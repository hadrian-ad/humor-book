Appendix

We can compare clips to see how small mistakes and small OKs can generate humor in the same way large mistakes and large OKs can generate humor.

We can do this with large mistake, large OK shows, like Family Guy (45 seconds):

https://youtu.be/yodDM6vaTno?t=25

And with medium mistake, medium OK shows, like The Office: (95 seconds):

https://youtu.be/-nkZ7y2y3LI

We can practice noticing that we can sort mistakes and OKs by comparative size. Does the jousting scene have a larger mistake (more deviation from the expected) and a larger OK (more security from negative consequences) than the dining scene? With practice, we can intuitively be aware of these sizes. Eventually, this lets us be consistent and precise in a given emotional situation.

Consider:

Note that we don't have to feel humor ourselves when watching these clips before we can think about why someone like Owen did or didn't feel humor from them. If our mistakes and OKs aren't balanced, we might find either of these clips to be uncomfortable, boring, in bad taste, and so on. But if Owen laughs, we can think about how he's evaluating things, and why that might be the case for him specifically.
